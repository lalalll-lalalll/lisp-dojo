# 📖 Lisp Dojo

欢迎来到 Lisp Dojo！这是一个致力于 Lisp 编程语言家族的在线知识库。

我们的愿景是在遵守版权协议的前提下，将优秀的 Lisp 书籍、文献、文章和文档转换为 Markdown 格式，并翻译成中文，同时也欢迎其他语言的翻译贡献。

## 📖 项目概览

- **技术驱动**：基于 VitePress 构建，追求简单、高效与稳定。
- **架构清晰**：内容与样式分离，确保项目的可维护性与容错性。
- **互动社区**：集成 [giscus](https://giscus.app/zh-CN) 评论系统，打造技术交流与学习平台（开发中...）。
- **纯粹阅读**：以 Markdown 格式呈现，提供沉浸、快捷的阅读体验。
