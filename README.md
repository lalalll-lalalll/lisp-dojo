# 📖 Lisp Dojo

Welcome to **Lisp Dojo**! This is an online knowledge base dedicated to the Lisp programming language family.

Our vision is to convert excellent Lisp books, papers, articles, and documentation into Markdown format and translate them into Chinese, all while strictly adhering to copyright agreements. Contributions in other languages are also warmly welcome.

## 📖 Project Overview

- **Tech-Driven:** Built on **VitePress**, aiming for simplicity, efficiency, and stability.
- **Clean Architecture:** Separation of content and style ensures maintainability and robustness.
- **Interactive Community:** Integrated with [giscus](https://giscus.app/) for technical exchange and learning (Under development...).
- **Pure Reading:** Presented in native Markdown format for an immersive and accessible reading experience.
